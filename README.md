# Optimization-of-Box-Girder-Bridges-
Cost-effective design and structural enhancements of pre-stressed concrete bridges 

A project focused on the cost optimization and structural enhancement of prestressed concrete box girder bridges using optimization techniques and computational methods. The project combines bridge engineering concepts with Python-based optimization approaches to achieve economical and structurally efficient bridge designs.

Optimization Parameters - 

Span length
Girder depth
Prestressing area
Deflection constraints
Construction cost

Constraints Used - 

Span Length: 20 m ≤ Span ≤ 40 m
Girder Depth: 2 m ≤ Depth ≤ 4 m
Prestressing Area: 200 cm² ≤ Area ≤ 500 cm²
Deflection ≤ Span / 250
